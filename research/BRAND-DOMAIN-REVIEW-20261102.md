# ExactUnit 品牌与正式域名决策门槛（2026-11-02）

## 已核实的公开事实

- 项目仓库当前使用 **ExactUnit** 作为网站品牌，但尚未有明确的正式自有域名；`convert-units-bwa.pages.dev` 是 Cloudflare 预览地址，不应视为用户购买的正式域名。
- https://exactunit.com/ 是另一家现有的单位换算网站，页面标题为 **ExactUnit | Simple, Fast Unit Conversions**，也包含英制/公制换算、分类目录和相关指南。（公开网页检索，2026-11-02）
- https://exactunitconverter.com/ 的标题和品牌文字使用 **ExactUnitConverter.com**，同样提供单位转换工具。（公开网页检索，2026-11-02）

这些证据能够确认**同名网站/高度接近名称的同类产品已存在**，不能据此断言商标侵权、恶意仿冒、Google 一定不收录或具体 SEO 流量损失。尚未进行目标国家正式商标数据库审查。

## 上线前必须决定

1. 正式品牌与域名应共同确定，优先选择实际可注册/可长期使用且不容易与同类网站混淆的名称；**不得因为 `pages.dev` 生成了 URL 就当作正式域名**。
2. 核对正式品牌的域名状态、商标注册/近似情况和搜索结果。域名可用性和商标状态都需以决策当时的真实查询为准。
3. 仅在品牌获得确认后，才统一替换页面页眉、页脚、title/OG/结构化数据、图标文案、`DESIGN.md` 和浏览器测试预期，并做全站构建验证。
4. 品牌变动不应改变已有的关键词主意图、37 个方向页、92 个数字页路径、索引试点和转换公式；不要为避开重名而创造低质量 SEO 页面。

**当前临时决策：**保持代码中的 ExactUnit 作为待定开发标签，不购买同名域名、不宣称是唯一品牌，也不自动做全站改名；待用户选择最终品牌后统一处理。
