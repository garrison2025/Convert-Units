# ExactUnit — Convert-Units

Free, browser-local unit conversion website following the owner-approved V2.0 specification.

**Project scope:** 37 conversion tool routes, one universal converter, 92 curated numeric SEO pages, 16 categories, batch conversion and CSV export. The complete tested source package is also supplied as a conversation artifact.

**Build:** Node.js 20+, `npm run check`, `npm run build`; Cloudflare Pages output: `dist`. Set build-time `SITE_URL` to the final origin before enabling Google indexing.

This repository is being populated from the verified source package; site deployment is not yet verified.
